# 🚗 Sistema Automotriz Profesional

Sistema completo para taller automotriz desarrollado por Fernando Millán.

## 🌐 Ver Demo

**[Abrir Aplicación](https://84-fmil-mel30.github.io/sistema-automotriz-pro)**

## Características

- Scanner OBD2 bidireccional
- Base de datos técnica 1990-2025
- Gestión de inventario
- Diagramas de cableado a color
- Programación de llaves

## Instalación

Abre la app en Chrome y presiona "Instalar" para usarla como app nativa.

## Acceso Admin

Clave: `1234`
